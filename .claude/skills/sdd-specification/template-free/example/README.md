# Ejemplo completo de especificación de una feature libre

Esta carpeta es un ejemplo **instanciado** de una especificación terminada con la plantilla `free`: la de un «aviso global de mantenimiento», un banner que el administrador configura y que ven todos los usuarios de todos los centros en todas las pantallas.
Es una feature libre porque toca la base común de la aplicación (el marco donde se pintan todas las pantallas) y la administración, sin ser un sistema ni un expediente.

- `specification.md` — la spec entera en un único fichero (lo normal en esta plantilla): objetivo, contexto, actores, historias con escenarios (incluido uno de no-regresión), requisitos, seguridad, recursos y fuera de alcance.

No hay anexos: ninguno de sus apartados se desbordó.
