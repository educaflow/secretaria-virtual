# Pantalla: Formulario de solicitud (alumno)

## Identidad

- **Quién la usa:** Alumno.
- **Qué muestra:** el alta de una solicitud eligiendo el tipo de certificado. Tras enviarla, queda en solo lectura.

## Menú

- No se abre desde un menú: se abre desde el listado «Mis certificados» al pulsar «Nueva solicitud».

## Paneles

- **Solicitud** — tipo de certificado

## Botones

- **Enviar** — Registra la solicitud, que queda en estado PENDIENTE.

## Reglas de UI

- RUI-001 — Al crear una solicitud, el alumno se rellena con el usuario actual
  - disparador: al crear
  - condición: Siempre
