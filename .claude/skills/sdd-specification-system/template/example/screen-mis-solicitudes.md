# Pantalla: Listado de mis solicitudes

## Identidad

- **Quién la usa:** Alumno (sus propias solicitudes), Exalumno y Familiar en solo lectura.
- **Qué muestra:** las solicitudes del alumno conectado con su estado, en modo lectura; permite crear una solicitud nueva.

## Menú

- Secretaría → Mis certificados — lo ve el Alumno; lleva a esta pantalla.

## Paneles

- **Listado** — tipo de certificado, fecha de solicitud, estado

## Botones

- **Nueva solicitud** — Abre el formulario de alta de una solicitud. Solo visible para el Alumno.

(Esta pantalla no tiene reglas de UI propias: el filtrado «solo veo las mías» es alcance de rol y vive en Seguridad, no como `RUI`. Por eso se omite la sección «Reglas de UI».)
